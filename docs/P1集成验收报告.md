# Auto Voucher P1 集成验收报告

> 结论：飞书审批与金蝶云·星空适配器的协议实现、状态机、界面和模拟合同测试完成。
> 发布边界：尚未取得真实飞书测试租户和金蝶测试账套，因此 P1 真实环境发布验收未完成。

## 1. 本次完成范围

### 飞书审批 v4

- 使用企业应用身份取得租户访问令牌；
- 探测审批定义范围和增量同步能力；
- 按时间游标拉取实例详情，只接收状态明确为 `APPROVED` 的实例；
- 按审批控件 ID 映射业务日期、客商、金额和审批单号；
- 同一外部实例重复同步时更新状态而不重复创建业务事项；
- 原始审批响应按内容哈希保存到本地归档；
- 映射不足时进入异常中心，不用猜测值继续生成凭证。

### 金蝶云·星空 WebAPI v6

- 登录指定数据中心，探测账套和可用能力；
- 通过动态查询同步目标科目和客商，在本地保留版本及原始响应；
- 推送前检查凭证确认状态、来源审批、连接器环境锁、保存草稿能力、会计期间、目标科目和辅助核算；
- 固定调用 Save 保存凭证草稿，明确关闭自动提交审核；
- 保存后使用 View 回查外部 ID、编号和状态；
- 网络结果不明时按幂等引用查询，仍未找到则进入人工核对并禁止自动重发；
- 映射认证、权限、限流、期间、主数据和字段校验错误到可执行的处理建议。

## 2. 安全与环境

- 密码和 App Secret 只通过操作系统密钥库存取，不写入 SQLite、日志或备份；
- 配置元数据采用白名单，拒绝把 password、token、secret 等字段写入业务状态；
- 生产目标要求 HTTPS；
- 生产目标要求专用最小权限账号并拒绝已知管理员账号；
- 目标地址、账套、审批定义或环境变化会使上次连接测试和环境锁失效；
- 切换生产环境与执行生产推送分别要求明确输入确认；
- 真实财务连接器不暴露提交、审核和过账操作。

## 3. 自动化证据

- 前端领域测试：18 项通过；
- 后端测试：46 项通过，其中连接器和编排测试覆盖能力探测、分页增量同步、字段映射、原始响应归档、主数据、可配置期间和账簿/报表只读查询、环境锁、最小权限、结构化诊断、保存草稿、主动查询、回查、超时和未知状态；
- Vite 生产构建通过；
- Chrome 桌面视口 `1710 × 836` 回归：页面宽度占满浏览器内容区，无横向溢出，未配置连接器的同步按钮不可用，控制台无警告或错误；
- 视觉继续使用已确认的 Airbnb 暖珊瑚 + 薄荷透明毛玻璃桌面工作台体系，不提供移动端布局。
