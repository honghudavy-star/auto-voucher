# Auto Voucher v0.2.1 发布说明

发布日期：2026-07-26

Auto Voucher v0.2.1 是一次面向新用户的界面可用性更新，重点解决首次配置表单拥挤、凭证工作台层级难以理解以及展开菜单无法收起的问题。

## 下载与系统要求

- 系统：Windows 10 22H2 或 Windows 11 x64
- 安装方式：[下载稳定版安装器](https://updates.iagent7.com/auto-voucher/stable/AutoVoucher-Setup-windows-x64.exe)
- 权限：按用户安装，无需管理员权限
- 网络：首次安装需要联网；已有完整版本可离线启动

安装器未使用 Authenticode 代码签名，因此 Windows 可能显示“未知发布者”。请只从本仓库或上面的官方更新地址下载，并核对 GitHub Release 公布的 SHA-256。

## 本次改进

### 更清楚的首次配置

- 企业、账套和目标 ERP 字段使用响应式网格排列，避免标签与输入框挤在同一行。
- 输入框、下拉框、焦点状态和分组间距统一使用现有暖珊瑚毛玻璃视觉。
- 自动化业务场景和生成方案操作区分开呈现。

### 更容易理解的凭证工作台

凭证工作台内部保留五个日常步骤：

1. 导入资料：文件、审批与流水。
2. 业务事项：识别结果与异常。
3. 生成与复核：凭证草稿与人工确认。
4. 推送状态：预检、推送与回查。
5. 查询审计：凭证与操作记录。

连接器、OCR、通用设置、诊断日志和备份恢复不再与日常流程混排，统一放入独立一级入口“系统工具”。

凭证工作台和系统工具均可再次点击收起；展开其中一个入口时，另一个会保持收起。

## 兼容性与安全边界

- 本版本不改变数据库结构、凭证生成规则、审批状态、推送合同或连接器能力。
- 现有 `v0.2.0` 用户可以通过启动器升级。
- 所有连接器仍只保存凭证草稿，不自动提交、审核、过账或结账。
- ERP 适配器的自动化合同测试不等于客户真实环境验收。

## 反馈问题

遇到问题时，请在“系统与数据 → 环境检测”或“系统工具 → 诊断日志”中复制脱敏问题信息，然后在 [GitHub Issues](https://github.com/honghudavy-star/auto-voucher/issues) 提交。请不要上传客户票据原文、连接器密钥、Token、数据库或其他财务数据。
