# Auto Voucher v0.2.0 发布说明

发布日期：2026-07-26

Auto Voucher v0.2.0 是首个面向公开体验的 Windows 版本。它采用“轻量启动器 + 本地核心程序 + 系统浏览器工作台”，不要求用户预先安装 Python、Node.js 或数据库。

## 下载与系统要求

- 系统：Windows 10 22H2 或 Windows 11 x64
- 安装方式：[下载稳定版安装器](https://updates.iagent7.com/auto-voucher/downloads/stable/AutoVoucher-Setup-windows-x64.exe)
- 权限：按用户安装，无需管理员权限
- 网络：首次安装需要联网；已有完整版本可离线启动

安装器未使用 Authenticode 代码签名，因此 Windows 可能显示“未知发布者”。请只从本仓库或上面的官方更新地址下载，并核对 GitHub Release 公布的 SHA-256。

## 本次重点

### 五入口生产工作台

1. **接入方案**：选择企业、目标 ERP、数据来源和业务场景，生成确定性数据流程。
2. **系统与数据**：管理 API、文件模板、测试账套和基础资料。
3. **凭证规则**：维护字段、科目、辅助核算和异常阻断规则。
4. **测试上线**：验证连接、期间、主数据、草稿保存、回查、幂等与财务确认。
5. **凭证工作台**：导入、识别、生成、复核、推送、查询和审计。

### 面向真实生产的安全约束

- 全新状态不包含示例公司、示例账簿、默认规则或演示连接器。
- 文件导入的审批状态默认为未知，匹配置信度由真实证据计算。
- 未完成测试上线门槛时，生产导出和推送保持禁用。
- 外部连接器只保存凭证草稿，不自动提交、审核、过账或结账。
- 修改目标系统、账套、规则或模板后，已有生产就绪状态自动失效。

### Windows 启动、更新与诊断

- 首次运行自动检测系统、目录、端口、磁盘、SQLite、网络和浏览器能力。
- 普通更新后台下载，工作台空闲并完成备份后才允许切换版本。
- 新版本健康检查失败时自动恢复旧版本和更新前数据库。
- 错误旁可一键复制脱敏问题信息；日志和诊断包不会自动上传。
- OCR 与 PDF 作为按需组件，缺失时不阻断表格、API 和基础工作台。

## ERP 与数据来源

本版提供飞书审批，以及金蝶云星空、用友 U8 V12+、浪潮海岳 GS Cloud 的版本化适配器框架；同时支持 CSV、XLSX、XML、XBRL、OFD、PDF、图片和银行流水文件。

需要特别说明：自动化合同测试证明了程序的调用边界和异常处理，但不等同于某个客户环境已经连接成功。真实上线必须取得客户的产品版本、接口文档、权限账号、基础资料和测试账套，并完成保存草稿与回查验收。

## 校验

正式发布流程会执行前端、后端、Go 启动器、构建、依赖审计、Actionlint、Gitleaks、签名清单、R2 上传和公开下载回读。公开安装器的文件大小与 SHA-256 以 [GitHub Release](https://github.com/honghudavy-star/auto-voucher/releases/tag/v0.2.0) 为准。

## 反馈问题

遇到问题时，请在“系统与数据 → 环境检测”或诊断中心点击“一键复制问题信息”，然后在 [GitHub Issues](https://github.com/honghudavy-star/auto-voucher/issues) 提交。请不要上传客户票据原文、连接器密钥、Token、数据库或其他财务数据。
