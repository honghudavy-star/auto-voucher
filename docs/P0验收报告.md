# Auto Voucher P0 验收报告

> 日期：2026-07-25
> 结论：P0 本地文件闭环与轻量启动/更新代码完成；发布状态为“待 Windows 签名产物验收”。
> 边界：仓库已删除演示连接器和前端种子数据；合同测试不代表真实厂商环境已经接通。

## 1. 已验收闭环

1. CSV、XLSX、XML、文本 PDF、扫描 PDF 和图片进入本地导入任务。
2. 原件按 SHA-256 去重并内容寻址归档，失败文件不污染去重索引。
3. 结构化资料按业务唯一键归并；重复发票/流水占用和金额差异创建阻断异常。
4. 图片和扫描 PDF 使用本地 RapidOCR 生成候选；日期、主体、金额、发票号和税号经人工确认后才创建事项。
5. 金额差异可由财务人员确认部分付款/差额拆分，原金额、本次金额、剩余金额和操作者均保留。
6. 结构化规则按优先级匹配业务类型和客商，生成时保存规则 ID、版本、借贷科目和逐行解释。
7. 凭证支持编辑、必填辅助核算、借贷平衡、批量确认、退回和已确认后重新编辑撤销确认。
8. 通用 XLSX 导出返回 SHA-256；导出、确认、修改和异常解决写入审计记录。
9. 金蝶、用友、浪潮适配器统一执行幂等键、Outbox、只保存草稿和回查；不明超时禁止自动重发，取得真实外部 ID 后才显示已推送。
10. 本地查询支持凭证、原件/事项双向追溯、科目汇总和操作日志；大列表限制单次渲染 100 行。
11. 备份包含状态、SQLite 快照和原件，逐文件校验 SHA-256；恢复前预览范围并在覆盖前确认。
12. 连接器密钥只允许写入操作系统密钥库；日志脱敏，密钥不进入 SQLite 或备份。
