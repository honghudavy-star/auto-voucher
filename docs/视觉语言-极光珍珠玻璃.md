# Auto Voucher 视觉语言：极光珍珠玻璃

> 历史方案：已被“Airbnb 暖珊瑚透明毛玻璃”方案替代。当前程序不得使用本文件中的紫色品牌 Token；本文件仅保留最初参考图的提炼过程。

> 来源：用户提供的移动端视觉参考
> 视觉名称：Aurora Pearl Glass / 极光珍珠玻璃
> 适用范围：品牌页、欢迎页、工作台氛围层、上传区、空状态、轻量数据概览
> 克制使用：凭证编辑器、明细账、报表表格、异常处理等高密度工作区

## 1. 视觉定义

这套视觉的核心不是简单的“紫粉渐变”，而是五个要素的组合：

1. 珍珠白底色；
2. 大面积、低边界感的极光色晕；
3. 半透明的柔雾玻璃；
4. 轻盈、纤细、低压迫感的排版；
5. 圆润、漂浮、带有柔和体积感的组件。

整体感受：

- 梦幻；
- 安静；
- 柔和；
- 未来感；
- 有呼吸感；
- 亲近而不科技冰冷。

用于 Auto Voucher 时，应把“梦境感”转译成“财务工作中的轻松、清晰和秩序”，而不是把整个产品做成低对比度的艺术作品。

## 2. 设计参数

### 2.1 原参考图

| 参数 | 建议值 | 说明 |
|---|---:|---|
| 视觉变化 | 7/10 | 大图、色晕和漂浮元素占据主要视觉 |
| 动效强度 | 5/10 | 适合缓慢漂移、呼吸和柔和切换 |
| 信息密度 | 3/10 | 留白多，单屏内容少 |

### 2.2 Auto Voucher 产品适配

| 参数 | 建议值 | 说明 |
|---|---:|---|
| 视觉变化 | 5/10 | 保留品牌特征，但不干扰工作流 |
| 动效强度 | 4/10 | 只用于状态切换、上传和成功反馈 |
| 信息密度 | 6/10 | 满足凭证、异常和报表的工作效率 |

## 3. 色彩系统

### 3.1 基础色

| Token | 建议色值 | 用途 |
|---|---|---|
| `canvas` | `#F7F2FB` | 页面基础背景 |
| `canvas-soft` | `#F1EBF7` | 次级背景 |
| `surface` | `rgba(255,255,255,0.78)` | 主要面板 |
| `surface-strong` | `#FCFAFD` | 表格、编辑器、表单 |
| `surface-muted` | `rgba(248,244,252,0.82)` | 次级区块 |
| `ink-primary` | `#2E2944` | 主文字 |
| `ink-secondary` | `#746C89` | 辅助文字 |
| `ink-tertiary` | `#9B93AD` | 占位和弱提示 |
| `border-soft` | `rgba(84,70,120,0.10)` | 普通边框 |
| `border-highlight` | `rgba(255,255,255,0.72)` | 玻璃高光边 |

### 3.2 品牌极光色

| Token | 建议色值 | 用途 |
|---|---|---|
| `aurora-violet` | `#8B7BE8` | 品牌主色 |
| `aurora-lilac` | `#C7A6F2` | 柔和过渡 |
| `aurora-pink` | `#F29AC2` | 温度和情绪 |
| `aurora-coral` | `#FF806C` | 小面积暖色焦点 |
| `aurora-blue` | `#A8B7F2` | 冷色平衡 |
| `deep-indigo` | `#4E4B80` | 高对比主按钮、选中状态 |

### 3.3 语义色

极光颜色只代表品牌氛围，不代表财务状态。业务状态使用独立且稳定的语义色：

| 状态 | 建议色 | 使用原则 |
|---|---|---|
| 成功/已完成 | `#237A57` | 图标、文字、浅底，不做渐变 |
| 警告/待确认 | `#A96912` | 金额差异、待补资料 |
| 错误/阻断 | `#B33A4B` | 重复发票、借贷不平、推送失败 |
| 信息/处理中 | `#4267A9` | 同步、解析、处理中 |

不得用紫粉红色表达“错误”，也不得用渐变颜色代替明确的成功、警告和错误状态。

## 4. 极光背景

### 4.1 构成

背景由 3-5 个大尺寸径向色晕叠加：

- 冷紫色位于右上或左侧；
- 粉色位于中下部；
- 珊瑚色只占一个小焦点；
- 大部分区域保持珍珠白；
- 色晕没有清晰边缘。

概念配方：

```css
background:
  radial-gradient(circle at 78% 18%, rgb(139 123 232 / 0.42), transparent 34%),
  radial-gradient(circle at 24% 54%, rgb(199 166 242 / 0.30), transparent 38%),
  radial-gradient(circle at 70% 68%, rgb(242 154 194 / 0.34), transparent 36%),
  radial-gradient(circle at 88% 74%, rgb(255 128 108 / 0.22), transparent 24%),
  #F7F2FB;
```

### 4.2 使用比例

| 页面 | 极光占比 | 建议 |
|---|---:|---|
| 欢迎/首次使用 | 70-80% | 可使用完整品牌氛围和大幅视觉 |
| 工作台 | 20-30% | 只在顶部欢迎区和摘要区出现 |
| 上传数据 | 20% | 用于上传区背景和完成反馈 |
| 凭证编辑器 | 5-10% | 只保留页面外层背景 |
| 异常中心 | 0-5% | 以语义状态清晰为先 |
| 账簿/报表 | 0% | 使用稳定纯色表面 |

### 4.3 禁止项

- 不在表格行后方放彩色渐变；
- 不在正文文字后放高饱和色晕；
- 不让多个组件各自拥有一套渐变；
- 不使用高亮霓虹外发光；
- 不用动画色晕持续干扰财务数据阅读。

## 5. 材质系统

### 5.1 珍珠玻璃

玻璃感来自四层，而不是单纯透明：

1. 半透明白色填充；
2. 背景模糊；
3. 顶部或内侧高光边；
4. 与背景同色系的柔和阴影。

建议参数：

```css
.pearl-glass {
  background: rgb(255 255 255 / 0.72);
  border: 1px solid rgb(255 255 255 / 0.68);
  backdrop-filter: blur(24px) saturate(145%);
  box-shadow:
    inset 0 1px 0 rgb(255 255 255 / 0.72),
    0 20px 50px rgb(92 74 135 / 0.12);
}
```

### 5.2 实心工作表面

凭证编辑、明细表格和表单使用接近实心的表面：

```css
.work-surface {
  background: #FCFAFD;
  border: 1px solid rgb(84 70 120 / 0.10);
  box-shadow: 0 12px 32px rgb(92 74 135 / 0.08);
}
```

原则：氛围层可以透明，数据层必须清晰。

### 5.3 透明度降级

当系统或浏览器启用“减少透明度”时：

- 移除背景模糊；
- 使用 `#FCFAFD` 实心背景；
- 保留边框和层级；
- 不影响文字对比度和状态识别。

## 6. 形状与圆角

### 6.1 圆角规则

| 对象 | 圆角 |
|---|---:|
| 应用主窗口/大型欢迎面板 | 28px |
| 主要内容面板 | 20px |
| 普通卡片/弹窗 | 16px |
| 输入框/下拉框 | 12px |
| 标签 | 8-10px |
| 主按钮/分段控制 | 全圆角 |
| 图标按钮 | 圆形 |

按钮可以是胶囊形，但表格、输入框和所有内容面板不能全部做成胶囊。

### 6.2 体积感

- 外轮廓柔和；
- 高光集中在上边缘；
- 阴影扩散而轻；
- 不使用深黑硬阴影；
- 不使用厚重边框；
- 选中状态主要通过实色和对比表达。

## 7. 排版

### 7.1 字体方向

使用现代、人文、圆润但不幼稚的无衬线字体：

- 中文：MiSans、HarmonyOS Sans SC、思源黑体；
- 英文和数字：Geist、Satoshi、SF Pro 风格字体；
- 表格数字启用等宽数字 `font-variant-numeric: tabular-nums`。

### 7.2 字级

| 层级 | 建议 |
|---|---|
| 欢迎页主标题 | 40-48px / 400-500 |
| 页面标题 | 26-32px / 500 |
| 区块标题 | 18-20px / 500-600 |
| 正文 | 14-16px / 400 |
| 表格 | 13-14px / 400-500 |
| 辅助文字 | 12-13px / 400 |
| 关键金额 | 24-32px / 500-600，等宽数字 |

### 7.3 特征

- 大标题字重偏轻；
- 字间距略紧；
- 正文行距舒展；
- 小字号不使用极浅紫灰；
- 金额和状态不使用渐变文字；
- 中文正文避免过细字重。

## 8. 图标

- 使用单一线性图标家族；
- 线宽统一为 1.5-1.75px；
- 端点和转角圆润；
- 默认使用深靛灰；
- 选中状态可以使用实心底和反白图标；
- 不混用手绘图标、Emoji 和多套图标库；
- 图标只承担识别，不代替文字说明。

建议组件开发时选用 Phosphor Icons 或 HugeIcons。

## 9. 组件语言

### 9.1 主按钮

- 胶囊形；
- 深靛色或紫粉低饱和渐变；
- 白色文字；
- 不加外发光；
- 按下时轻微缩小；
- 同一页面只保留一个主操作。

建议渐变：

```css
background: linear-gradient(100deg, #F2A7BE 0%, #8B74E8 100%);
```

在高频工作页面中，主按钮优先使用实色 `#4E4B80`，减少视觉疲劳。

### 9.2 次按钮

- 珍珠白或透明玻璃；
- 深色文字；
- 细边框；
- Hover 时增加轻微底色；
- 不与主按钮使用相同视觉重量。

### 9.3 分段控制

参考图中的 Week / Month / All Time：

- 外层为浅色玻璃；
- 选中项使用深靛实色；
- 未选项保持低对比；
- 切换时滑块平滑移动；
- 只用于 2-4 个互斥选项。

### 9.4 标签

- 小圆角而非全胶囊；
- 低饱和浅底；
- 不给每个标签不同颜色；
- 语义标签使用成功、警告、错误的稳定色系；
- 标签文字保持 12-13px。

### 9.5 卡片

- 卡片只用于真实层级；
- 卡片之间主要通过留白区分；
- 工作台摘要卡可以使用淡玻璃；
- 凭证分录、异常明细和表格不要每行套卡片；
- 同一区域最多保留两层玻璃。

### 9.6 表格

表格是该视觉落地时最需要克制的部分：

- 使用实心浅色背景；
- 表头可使用极浅薰衣草灰；
- 行分隔线非常轻；
- Hover 只增加淡紫灰底；
- 选中行使用左侧强调线或浅底；
- 金额右对齐；
- 异常状态使用语义色；
- 不使用渐变表头；
- 不在每个单元格内放玻璃胶囊。

## 10. 图片与品牌视觉

原图使用“梦境球体、鲸鱼、云层、柔焦光晕”作为情绪主体。这类视觉适合：

- 欢迎页；
- 空状态；
- 数据导入完成；
- 月度结账完成；
- 品牌宣传页。

Auto Voucher 的图像母题不应照搬鲸鱼和梦境，而应转译为：

- 漂浮的票据薄片；
- 柔和连接的单据关系；
- 在透明球体中逐步成形的凭证；
- 文件从混乱到有序排列；
- 抽象的借贷平衡轨迹；
- 柔光包裹的归档盒或账簿。

品牌视觉表达“复杂资料被整理成清晰凭证”，而不是单纯追求梦幻。

## 11. 动效

### 11.1 动效原则

每个动效必须表达以下一种含义：

- 层级；
- 状态变化；
- 处理进度；
- 操作反馈；
- 资料从分散到归并。

### 11.2 推荐动效

| 场景 | 动效 |
|---|---|
| 文件拖入 | 上传区轻微扩张，边缘色彩增强 |
| 文件解析 | 文件缩略图依次归入业务事项 |
| 自动匹配 | 资料间连接线短暂出现 |
| 生成凭证 | 分录按顺序淡入，不做弹跳 |
| 异常出现 | 对应字段柔和高亮一次 |
| 成功推送 | 凭证号从处理中切换为已回查 |
| 分段切换 | 选中底块平滑滑动 |

### 11.3 参数

- 常规反馈：160-220ms；
- 面板切换：240-320ms；
- 页面进入：350-450ms；
- 缓动：`cubic-bezier(0.16, 1, 0.3, 1)`；
- 只动画 `transform` 和 `opacity`；
- 遵循 `prefers-reduced-motion`。

不使用持续漂浮、视差或背景动画干扰凭证编辑和报表阅读。

## 12. 页面应用建议

### 12.1 欢迎页

视觉强度：80%

- 珍珠白背景；
- 大面积紫粉蓝极光；
- 一张抽象品牌主视觉；
- 简洁标题和一个主按钮；
- 不展示复杂功能清单。

### 12.2 工作台

视觉强度：30%

- 顶部欢迎区保留极光；
- 待处理数字使用实色文字；
- 摘要卡使用轻玻璃；
- 异常和推送状态使用清晰语义色；
- 主列表使用实心表面。

### 12.3 导入数据

视觉强度：25%

- 上传区是主要品牌组件；
- 空状态可使用票据漂浮视觉；
- 文件列表回到清晰实心表面；
- 导入结果用数字和明确状态表达。

### 12.4 凭证编辑器

视觉强度：10%

- 页面外层可见很淡的极光；
- 原始资料和分录区域均用实心表面；
- 分录编辑器保持高对比；
- 主操作使用深靛实色；
- 不使用透明表格。

### 12.5 异常中心

视觉强度：5%

- 以红、橙、蓝语义色为主；
- 极光色只出现在页面背景边缘；
- 每个异常明确显示原因、差额和解决操作；
- 不以情绪色替代错误级别。

### 12.6 查询与报表

视觉强度：0-5%

- 纯净背景；
- 稳定表格和图表；
- 品牌色仅用于选中状态、关键链接和图表主系列；
- 图表不得同时使用整套紫粉渐变造成系列难以区分。

## 13. 无障碍与可读性

- 正文文字达到 WCAG AA 对比度；
- 大面积渐变后方必须增加稳定表面或局部遮罩；
- 表单标签始终位于输入框上方；
- Placeholder 不代替标签；
- 焦点环使用清晰的深靛色；
- 状态不能只依赖颜色，还需图标和文字；
- 透明效果关闭后仍保持层级；
- 所有动效支持减少动态效果；
- 图表提供文字摘要和数据表替代。

## 14. 设计禁区

以下做法会破坏这套视觉在财务产品中的可用性：

- 整个页面都覆盖紫粉渐变；
- 所有面板都使用高透明玻璃；
- 灰紫小字直接放在复杂背景上；
- 用品牌粉色表示错误；
- 在凭证表格中大量使用圆形胶囊；
- 每张卡片都有发光和动画；
- 主按钮、次按钮、标签都使用相同渐变；
- 用梦境插画代替清晰的业务状态；
- 在报表中使用模糊背景；
- 在核心数据区使用过细字体；
- 为追求轻盈而降低金额和错误信息的对比度。

## 15. 一句话执行原则

**背景可以梦幻，数据必须清楚；容器可以柔和，状态必须明确；品牌可以轻盈，财务操作必须可信。**
