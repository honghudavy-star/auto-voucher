# Auto Voucher 视觉语言：Airbnb 暖珊瑚毛玻璃

> 状态：当前采用
> 适用范围：本地程序全部工作台页面
> 产品边界：仅桌面 Web 工作台，不设计移动端或手机响应式布局

## 核心气质

空间工作台、温暖、克制、可信。借用 Airbnb 的暖珊瑚色作为行动色，以透明毛玻璃建立空间层次；不使用紫色 AI 渐变、霓虹光效或聊天机器人式组件。

## 视觉要素

- 珍珠白到暖米白画布，边缘加入低饱和珊瑚与薄荷色雾；
- 主要面板使用半透明白、背景模糊、内侧高光边和柔和投影；
- 左侧固定导航、顶部工具栏、中央业务队列、右侧凭证预览；
- 高密度表格放在接近实心的白色工作表面上；
- 主行动使用 Airbnb 珊瑚红 `#FF5A5F`，导航选中使用炭黑；
- 成功用薄荷绿、待处理用琥珀色、阻断用红色，语义色不参与品牌渐变；
- 大圆角用于空间容器，小圆角用于按钮、标签和表格单元；
- 字体优先系统字体，金额使用等宽数字特性；
- 模糊、透明度和阴影只用于分层，不降低财务数据对比度。

## 使用边界

- 页面背景可以有极淡色雾，表格正文后方不得出现高饱和渐变；
- 毛玻璃面板必须提供无 `backdrop-filter` 时的实色降级；
- 主按钮每个局部工作区原则上只有一个；
- “已生成、已确认、已推送、已回查”必须使用文字明确区分，不能只依赖颜色；
- 动效只用于页面切换、上传、状态确认，且支持减少动态效果。
- 页面占满浏览器内容区，桌面最小宽度为 1180px；应用外壳不得出现模拟桌面窗口的外边距、圆角或留白。
