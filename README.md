# iAgent Finance · Auto Voucher

`finance.iagent7.com` 的前端视觉原型。首个展示产品 Auto Voucher 面向中国企业财务场景，表达从业务资料到可审核凭证草稿的本地优先工作方式。

本仓库目前只包含公开网站前端，不包含：

- Auto Voucher 后端或桌面应用；
- 企业财务数据、示例账套或客户资料；
- 产品需求、内部调研和设计过程文档；
- API 密钥、环境变量或部署凭据。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

构建产物位于 `dist/`，不会提交到 Git。

## 当前边界

这是可交互的前端展示页面，不代表 Auto Voucher 的完整产品能力。页面中的凭证、发票、银行流水和金额均为虚构演示内容。
